# Roadmap

## Before accepting public orders

- Approve actual restaurant location, operating hours, service areas, prices, allergens and production photography.
- Provide the missing homepage reference if fidelity comparison is still desired.
- Configure and verify hosting, TLS, managed database backups, S3, SMTP and error monitoring.
- Approve privacy notice, retention periods, customer support and cancellation policy.
- Complete a production security review, restore drill and realistic load test.

## Next product increments

- Server carts and cross-device continuity; paginated/searchable order history beyond the initial 100-record view.
- Branch-scoped staff assignments and a richer permission model.
- Pending-order expiration and automatic stock release; opening-hours and capacity rules.
- Required modifier groups, minimum/maximum selections, item variants and allergen metadata.
- Verified manual payment records if collected-revenue reporting is required.
- Email verification, MFA and expanded recovery controls.
- Redis-driven SSE wake-ups when polling measurements justify the added complexity.
- Official WhatsApp Cloud API only after business/sender credentials and messaging policy requirements are available.

No payment gateway is planned for the current checkout flow.
