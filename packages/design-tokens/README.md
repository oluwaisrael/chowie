# Óriade design tokens

The canonical CSS variables and Tailwind v4 theme are in `apps/storefront/src/app/globals.css`. Keeping one source avoids duplicated values during the single-app phase. Forest and cream define the brand; terracotta is reserved for focus and restrained accents. Display text uses Georgia; interface text uses a system Arial/Helvetica stack with no third-party font requests. Spacing follows a 4px base, with a 1,320px content container and 760px / 1,050px responsive boundaries.
